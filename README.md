# SIGNAL 🔍

> "Understand what the message is doing."

SIGNAL is an advanced AI-powered communication analysis tool designed to decode the underlying signals, emotional cues, persuasion patterns, and missing contexts behind what you see, read, or hear.

---

## 🌟 Key Features

* **📷 Screenshot Analysis:** Upload UI or messaging screenshots to extract text, evaluate visual framing, and uncover hidden persuasion tactics.
* **📝 Text Analysis:** Paste message content to analyze rhetoric, tone, and underlying intent.
* **🎙️ Voice Analysis:** Upload audio files or voice notes to transcribe speech, detect emotional levels, and analyze vocal delivery cues.
* **🧠 Structured Insights:** Get breakdowns across multiple layers:
  1. Summary
  2. Emotional Signals & Levels
  3. Persuasion Patterns
  4. Missing Context Identification
  5. Critical Reflection Questions ("Think Before You Share")

---

## 🛠️ Tech Stack

* **Frontend:** React.js, HTML5, Modern CSS, Babel standalone
* **Backend:** Node.js, Express.js server
* **AI Integration:** Multi-modal processing pipeline for text, image, and audio analysis.
